How to make your website public

1. Download the website HTML.
2. Create a separate public repository on GitHub for that website.
3. Upload the downloaded file as index.html.
4. Open the repository Settings, then Pages.
5. Select Deploy from a branch, choose main and /root, then save.
6. GitHub will give you a public website address to share.
